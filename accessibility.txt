=== Accessibility Statement ===
OceanWP is developed with accessibility in mind and aims to support the WordPress Accessibility-Ready Theme requirements.

Accessibility is reviewed as part of our theme development, testing, and maintenance workflow. OceanWP includes accessibility-related features for core theme functionality, including keyboard navigation support, skip link support, screen-reader text support, accessible search and menu controls where applicable, visible focus styles, improved link distinction, and semantic markup improvements.

To protect existing websites from unexpected layout or design changes, some newer accessibility enhancements are controlled through the "Accessibility - A11Y" Customizer panel. These enhancements are enabled by default for new installations and can be enabled, disabled, or adjusted by site administrators on existing installations.

For more information see: [WordPress Accessibility-Ready Guidelines](https://wpaccessibility.org/docs/topics/theme-guidelines/)

== Testing Tools and Methodology ==
Accessibility is reviewed as part of the OceanWP development and release process. Testing combines automated checks with manual review of common theme templates, layouts, and interactive components.

Current accessibility testing and review includes:
- **Automated Checks:** Browser-based accessibility testing tools are used to identify common issues such as missing labels, contrast concerns, invalid nesting, and structural problems.
- **Keyboard Testing:** Common navigation and interaction flows are manually tested with keyboard-only input, including menus, submenu toggles, search controls, modal-style interfaces, form controls, and skip links.
- **Screen Reader Text Review:** Screen-reader-only text and accessible labels are reviewed to ensure that controls provide useful context when visual text is not available.
- **Focus Visibility Review:** Interactive elements are reviewed for visible focus indication during keyboard navigation.
- **Responsive and Zoom Testing:** Theme layouts and common components are reviewed at different viewport sizes and browser zoom levels, including testing up to 400% zoom where practical.
- **Regression Review:** Accessibility-related fixes and reported issues are reviewed as part of ongoing theme maintenance and release testing.

Primary accessibility testing tools include:
- [The WAVE browser extension](https://wave.webaim.org/extension/).
- Browser developer tools in major browsers
- Keyboard-only navigation testing
- Screen-reader text and accessible-name inspection
- Heading structure review
- Browser zoom and responsive layout testing

== Accessibility Features ==
OceanWP includes the following accessibility-related features in core theme functionality:
- Skip to Content Link: A skip link is provided to allow keyboard users to bypass repeated navigation and move directly to the main content area.
- Screen Reader Text Utility: The .screen-reader-text class is supported for visually hidden text that remains available to assistive technologies.
- Keyboard Navigation Support: Core navigation and interactive theme controls are reviewed for keyboard operation.
- Visible Focus Styles: Keyboard focus indicators are provided for interactive elements.
- Accessible Navigation Menus: Theme navigation menus use list-based markup and include keyboard-accessible dropdown behavior where applicable.
- Accessible Controls: Search, menu, submenu, and media controls are reviewed for accessible names, roles, and states where applicable.
- Semantic Markup Improvements: OceanWP continues to modernize legacy markup with more appropriate semantic HTML in supported theme areas.
- Distinguishable Text Links: Inline text links in supported content areas and widgets include visual distinction that does not rely only on color.
- Contextual Read More Links: Blog, archive, and excerpt "Read More" links include additional screen-reader context where supported.
- Form Field Accessibility: Theme search and form patterns are reviewed for labels, accessible names, and visible label options where applicable.
- Header Media Controls: Supported video header implementations include accessible play and pause controls.
- External Link Indicators: Header and top bar social links can include configurable visual and screen-reader indicators when links open external destinations.
- Accessibility Customizer Panel: The "Accessibility - A11Y" panel allows site administrators to manage supported accessibility enhancements and compatibility options.

== Compatibility Notes ==
OceanWP is a highly configurable theme and may be used with custom menus, custom headers, page builders, WooCommerce, third-party plugins, custom CSS, and child themes. Site owners should test their final site configuration, content, color choices, plugins, and customizations for accessibility.

Some newer semantic markup and accessibility enhancements are controlled through the "Accessibility - A11Y" Customizer panel to preserve backward compatibility for existing websites.

The legacy Sidebar Mobile Header Style is maintained for backward compatibility. For the most accessible mobile navigation experience, we recommend using the supported Drop Down or Full Screen mobile header styles with the current accessibility enhancements enabled.
